# Card

A content container for grouping related information on the page canvas.

Set cards in `bg-card` on a `bg-page` background, with a `border` hairline, `radius-lg` corners and `shadow-md`. Pad with `space-6`. Use a Display style (`display-xl`) for the title, `body` `text-secondary` for supporting copy, and keep to one primary action. The round `radius-full` avatar/disc echoes the logo mark.

The consumer provides the heading, body content and any actions or media.

Foundational example built from the tokens. It shows surface, elevation and radius on a composed block.
