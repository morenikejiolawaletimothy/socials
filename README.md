# Bluecut Socials

Web app for Bluecut Socials, a social media and brand studio.

## Stack

Next.js 15, TypeScript, Tailwind CSS v4, Phosphor icons.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000. The design system reference lives at `/design-system`.

## Design system

Brand rules and tokens are in `design-system/`. Coded components are in `src/components/ui`. See `CLAUDE.md` for the rules every change follows.
